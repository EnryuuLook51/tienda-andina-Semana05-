# Tienda Andina — Semana 05

Aplicación de escritorio Java Swing para gestionar pedidos, desarrollada para la evaluación formativa de Arquitectura de Software Empresarial.

Implementa los patrones State, Strategy, Visitor, Observer y Repository. Los pagos, reembolsos y notificaciones son simulados.

## Ejecutar

Requiere JDK 21 o superior y un entorno gráfico.

```sh
cd tienda-andina
sh ejecutar.sh
```

Para ejecutar las pruebas:

```sh
cd tienda-andina
sh ejecutar.sh --pruebas
```
